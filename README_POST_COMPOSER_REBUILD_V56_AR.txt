EgyBook — إعادة بناء صفحة «منشور جديد» ومحرر الصور (v56)

الملفات المعدلة:
1) index.html
   - استبدال بنية HTML لواجهة إنشاء المنشور ومحرر الصور ببنية منظمة جديدة.
   - الحفاظ على المعرفات وأسماء data-action التي يعتمد عليها script.js.
   - إضافة تحميل ملف composer-rebuild.css.
2) styles.css
   - إزالة قواعد CSS القديمة المتخصصة في صفحة منشور جديد ومحرر الصور، والتي كانت متراكمة ومتعارضة.
   - لم تُحذف قواعد تصميم بقية صفحات الموقع عمدًا.
3) script.js
   - تعديل عزل الطبقات بحيث لا يجعل نافذة الخصوصية ومشغل الفيديو inert أثناء فتح واجهة المنشور.
4) composer-rebuild.css (ملف جديد)
   - تنسيق جديد مستقل للموبايل والكمبيوتر لواجهة المنشور ومحرر الصور ومشغل الفيديو.

التركيب:
- فك ضغط ZIP.
- ارفع الملفات المعدلة index.html وstyles.css وscript.js إلى مساراتها نفسها في المشروع.
- ارفع الملف الجديد composer-rebuild.css إلى جذر المشروع بجوار index.html.
- لا يوجد SQL مطلوب لهذا التعديل.
- رسالة Commit مقترحة: Clean rebuild of post composer and image editor

الاختبارات التي أُجريت:
- node --check script.js: نجح.
- تحليل قواعد CSS للملفين styles.css وcomposer-rebuild.css: لا توجد أخطاء parsing.
- فحص بنية HTML وتأكد وجود نسخة واحدة من المعرفات الأساسية: createPostModal وpostForm وpostContent وmediaPreview وimageEditorModal وimageEditorImage وimageEditorFilters وegybookVideoModal وegybookVideoPlayer وaudienceModal.
- اختبار سلامة ZIP بعد التصدير.

حدود معروفة يجب عدم اعتبارها مكتملة:
- أداة القص داخل محرر الصور ما زالت تعرض رسالة تفيد بأنها لم تُستكمل؛ لم أصفها كقص فعلي.
- لا يمكن اعتبار النشر الفعلي أو صلاحيات Supabase أو كل إيماءات الرجوع على أجهزة فعلية مختبرة هنا؛ يلزم اختبار الموقع المنشور على الهاتف والكمبيوتر.
- لا يتطلب هذا التعديل تغيير قاعدة البيانات.
