تحديث واجهة نافذة البحث - EgyBook v24

- نافذة البحث أعلى الشاشة على الهاتف.
- على الكمبيوتر تظهر قرب أعلى الصفحة ناحية اليمين.
- خلفية معتمة ومموهة تمنع تداخل الصفحة الخلفية.
- إغلاق بالضغط خارج الإطار أو زر الإغلاق أو Escape أو سحب لأسفل من أعلى النافذة.
- منع تمرير الصفحة الخلفية أثناء فتح البحث للحفاظ على موضعها.

الملفات المعدلة: index.html وscript.js وstyles.css.
لا توجد تغييرات على قاعدة البيانات أو SQL.
