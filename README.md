🇪🇬 EgyBook | إيجي بوك

منصة التواصل الاجتماعي المصرية — تواصل، شارك، اكتشف أكثر.

EgyBook is an Egyptian-inspired social networking platform designed to bring people together through sharing, conversations, and discovering new content.

✨ Features

- 🏠 Home Feed: Browse posts and discover content.
- ✍️ Create Posts: Share text, photos, and videos.
- ❤️ Likes: Interact with posts.
- 💬 Comments: Join conversations.
- 🔖 Save Posts: Keep posts for later.
- 🔍 Search: Find content.
- 📱 Responsive Design: Designed for mobile and desktop.
- 🌙 Modern Interface: Dark navy background with neon blue, cyan, and purple accents.
- 🇪🇬 Arabic Support: Arabic interface with right-to-left layout.

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

📁 Project Structure

EgyBook/
├── index.html
├── styles.css
├── script.js
└── README.md

🚀 Getting Started

1. Download or clone this repository.
2. Make sure all three website files are in the same directory.
3. Open "index.html" in your browser.

🌐 GitHub Pages Deployment

To publish EgyBook using GitHub Pages:

1. Open the repository settings.
2. Select Pages.
3. Choose the "main" branch.
4. Select the "/ (root)" folder.
5. Click Save.

Your website will be available at:

"https://Egybook.github.io/Egybook/"

⚠️ Current Limitations

This version is a front-end prototype. Some features use browser Local Storage and work only within the same browser on the same device.

Real user accounts, cross-device data synchronization, private messaging, live notifications, and a shared database require a backend server and database integration.

🎨 Visual Identity

- Primary: Dark Navy
- Secondary: Neon Blue
- Accent: Cyan and Purple
- Layout: Arabic RTL
- Design Goal: A modern, accessible, mobile-friendly Egyptian social platform.
