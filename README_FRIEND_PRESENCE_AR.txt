حالة الاتصال وآخر ظهور للأصدقاء فقط

- تمت إضافة حضور فوري عبر Supabase Realtime Presence.
- تظهر الحالة فقط بجانب الأصدقاء المقبولين في قائمة الأصدقاء وقسم الأصدقاء داخل الملف الشخصي، وليس بجانب الحسابات المقترحة أو طلبات الصداقة.
- لتفعيل آخر ظهور عند عدم الاتصال، شغّل EGYBOOK_FRIEND_PRESENCE_MIGRATION.sql مرة واحدة في Supabase SQL Editor.
- إذا لم يُشغّل الترحيل، سيظل تحميل قوائم الأصدقاء يعمل عبر استعلام احتياطي، لكن وقت آخر ظهور قد يظهر كـ «حالة الاتصال غير متاحة».
- حالة الاتصال تعتمد على قناة Realtime فعلية؛ لم يتم اختبارها مع مشروع Supabase الحي ضمن هذا التعديل.
