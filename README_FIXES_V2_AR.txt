EgyBook — إصلاحات إضافية

الملفات المستبدلة:
- index.html
- script.js
- styles.css

الملف الجديد:
- EgyBook_FOLLOWUP_COMPATIBILITY_FIX.sql

التغييرات:
1. ترتيب الهيدر: MEMEZ ثم الرسائل ثم الإشعارات ثم البحث من ناحية اليسار، مع بقاء الاسم والقائمة في اليمين.
2. تغيير شكل أيقونة الرسائل مع الحفاظ على أبعاد الزر الحالية.
3. شارة «مقروءة» لا تظهر إلا بعد فتح الإشعار، وإزالة أيقونات النوع من بطاقات التعليق والتفاعل لتقليل ارتفاعها.
4. إظهار تفاصيل الخطأ الفعلي إذا فشل طلب التوثيق بدل رسالة عامة مضللة.
5. ملف SQL الإضافي يصلح مقارنة UUID وTEXT في مشغل إشعارات التعليقات، ويضيف أعمدة التوافق اللازمة إذا كان جدول verification_requests موجودًا مسبقًا بمخطط أقدم.

مهم:
- ارفع الملفات الثلاثة المستبدلة إلى GitHub.
- نفّذ ملف EgyBook_FOLLOWUP_COMPATIBILITY_FIX.sql في Supabase SQL Editor.
- اختبر التعليق والرد وطلب التوثيق بحساب مستخدم عادي.
- لم يتم اختبار الموقع الحي أو قاعدة Supabase من هنا؛ تم فحص بنية الملفات وصياغة JavaScript فقط.
