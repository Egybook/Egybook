تحديث EgyBook — قائمة إجراءات التعليقات والردود

الملفات المعدلة:
- script.js: قائمة الضغط المطوّل، النسخ/المشاركة، التعديل والحذف، عرض علامة تم التعديل، حفظ تفاعلات التعليقات والردود بتحديث متفائل مع التراجع عند الفشل، ومحاولة إرسال إشعار عند ذكر مستخدم.
- styles.css: تصميم القوائم السفلية وواجهتي التعديل والحذف بهوية EgyBook مع دعم RTL وتقليل الحركة عند تفعيل إعداد تقليل الحركة.
- index.html: عناصر واجهات الإجراءات والتعديل والحذف.
- EGYBOOK_COMMENTS_ACTIONS_MIGRATION.sql: إضافة edited_at وسياسة إدخال إشعارات الإشارة.

مهم قبل اختبار التعديل/الإشارة:
1) افتح Supabase SQL Editor.
2) شغّل ملف EGYBOOK_COMMENTS_ACTIONS_MIGRATION.sql كاملًا.
3) تأكد أن جدول post_comments موجود وأن سياسة RLS تسمح لصاحب التعليق بتعديل/حذف صفه.
4) اختبر من حسابين مختلفين: تفاعل تعليق ورد، الضغط المطوّل، نسخ النص، تعديل وحذف محتوى تملكه، والإشارة إلى مستخدم آخر.

حدود التحقق:
- تم التحقق من صحة صياغة JavaScript باستخدام node --check.
- لم يتم تشغيل الموقع ضد مشروع Supabase الفعلي أو إجراء اختبار متصفح حي، لذلك يلزم تنفيذ ترحيل SQL والاختبار على الموقع قبل اعتبار جميع الوظائف مؤكدة.
