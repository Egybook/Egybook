# EgyBook V243 — حراسة تفعيل صوت Reels أثناء الانتقال

**التاريخ:** 25 نوفمبر 2026  
**النسخة الأساسية:** `EgyBook_V242_Node24_GitHub_Actions_Update.zip`  
**النطاق:** إصلاح محدود لدورة تسليم الصوت بين فيديو Reels المغادر والفيديو الداخل.

## الملاحظة التي عالجها الإصدار

أفاد اختبار الهاتف بأن بعض انتقالات Reels تصل إلى الفيديو الجديد دون صوت، بينما يعمل الصوت طبيعيًا عند مغادرة قسم Reels والعودة إليه. في مسار V241 كان مستمع `playing` يُسجّل قبل تبديل مصدر عنصر المشغل الأساسي، ويُستخدم مرة واحدة فقط، كما كان متغير `incomingAudioActivated` يُضبط قبل معرفة نتيجة التفعيل.

هذا يفتح سباقًا محتملًا: حدث `playing` قديم أو غير مطابق للمصدر الداخل قد يستهلك المستمع أو يقفل محاولة التفعيل قبل أن يبدأ المصدر الجديد فعليًا. لا تثبت تقارير الهاتف أن هذا هو السبب الوحيد لكل حالة، لكنه خلل توقيت قابل للإثبات في ترتيب الكود ويطابق نمط العَرَض.

## ما تغير

1. إضافة `isIncomingReady` إلى منسق Reels للتحقق من أن جلسة التسليم ما زالت الحالية، وأن عنصر الوسائط هو العنصر الداخل المُجهّز نفسه، وأنه ليس متوقفًا، وأن المصدر المعيّن والحالي يطابقان مصدر الفيديو المطلوب.
2. تفعيل الصوت في `script.js` أصبح مشروطًا ببدء طلب التشغيل وباجتياز حراسة المصدر الداخل.
3. لم يعد مستمع `playing` يُزال عند أول حدث؛ يظل مستعدًا لمحاولة لاحقة حتى ينجح التفعيل فعليًا.
4. لم يعد قفل `incomingAudioActivated` يُضبط قبل استجابة المنسق بالنجاح. أضيف قفل منفصل لمنع محاولات التفعيل المتزامنة.
5. أضيفت سجلات تشخيصية لمحاولات التفعيل المؤجلة أو أخطائها، مع عدم تسجيل رابط الوسيط أو بيانات حساسة.
6. تم تحديث مراجع الأصول ونسخة Cache الخاصة بـService Worker إلى V243.

## ما لم يتغير

- لم يتغير عنصر التشغيل الأساسي `#egybookVideoPlayer` أو عدد مشغلات الفيديو.
- لم يتغير `swipe-navigation.js` أو السحب الرأسي الواحد أو Push Transition أو عتبات السحب.
- بقيت معاينة السحب صامتة، والمشغل الأساسي هو مالك الصوت بعد التسليم.
- لم يتغير سلوك الخروج من Reels والعودة إليه، بما فيه بدء الفيديو من البداية كما طلب المستخدم.
- لم يتغير أي CSS أو شكل/موضع/أبعاد/حركة/سلوك للهيدر العلوي أو السفلي.
- لم تتغير أنظمة Home أو Profile أو Reels Return Recovery أو Persistent Navigation State أو Unified Video Player beyond the scoped audio guard.
- لا تغييرات على Supabase أو Neon أو R2 أو Workers أو Hovod أو قواعد البيانات أو SQL/RLS أو روابط الوسائط.
- لا نشر أو دفع إلى GitHub أو ترحيل لخدمة خارجية.
