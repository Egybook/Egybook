EgyBook — إصلاح تحميل التفاعلات والتعليقات وعرض الملف الشخصي

الملف المطلوب استبداله:
- script.js

لماذا؟
- تحميل عدد التفاعلات وعدد التعليقات من Supabase عند تحميل المنشورات.
- استرجاع تفاعل المستخدم الحالي من post_reactions بعد تحديث الصفحة.
- تحديث العدادات بعد حفظ/حذف التفاعل وبعد تحميل التعليقات.
- إظهار رسالة الخطأ الحقيقية من Supabase في حال فشل حفظ التفاعل، مع تسجيل تفاصيل التشخيص في console.
- منع صفحة الملف الشخصي العام من عرض منشورات الحساب الحالي أثناء انتظار تحميل ملف صاحب الصفحة، ثم إعادة عرض منشورات صاحب الملف بعد معرفة معرّفه الحقيقي.
- إخفاء زر تعديل الملف الشخصي عند زيارة ملف شخص آخر.

تنبيه:
- تم فحص JavaScript نحويًا باستخدام node --check فقط؛ لم يتم الاتصال بقاعدة Supabase الحية أو اختبار حسابات المستخدمين فعليًا.
- ملف SQL السابق لا يحتاج إلى إعادة التنفيذ لمجرد رفع هذا التعديل. لا تنفذ SQL إضافيًا قبل مراجعة سجل الخطأ إذا استمرت المشكلة.
- زر «إضافة صديق» ظاهر كواجهة فقط؛ نظام العلاقات/الصداقات يحتاج إلى جدول وسياسات وعمليات خلفية مستقلة قبل أن يعمل فعليًا.
- قبل الاستبدال احتفظ بنسخة من script.js الحالي.
