EgyBook — توحيد المنشورات والتفاعلات لحظيًا

الملف:
- script.js: نسخة معدلة لتحديث نسخ المنشور الموجودة في صفحات EgyBook المختلفة، وإضافة اشتراك Supabase Realtime على posts وpost_reactions وpost_comments.

ما الذي يفعله التعديل؟
- بعد جلب أعداد التفاعلات والتعليقات، ينسخ الحالة والعدادات إلى كل نسخة DOM تحمل نفس post_id، بما فيها نسخة الملف الشخصي أو عارض المنشور.
- يستمع إلى تغييرات المنشورات والتفاعلات والتعليقات من Supabase، ويحدّث الواجهة أثناء بقاء الصفحة مفتوحة.
- لا يتضمن SQL جديدًا ولا يحذف أي بيانات.

قبل النشر:
1. احتفظ بنسخة من script.js الحالي.
2. استبدل script.js في جذر مستودع GitHub بهذا الملف.
3. من Supabase Dashboard > Database > Publications/Replication، تأكد من تفعيل Realtime للجداول العامة:
   posts
   post_reactions
   post_comments
   إذا لم تكن الجداول مضافة إلى publication المسماة supabase_realtime، فلن تصل أحداث Realtime.
4. اختبر بحسابين: افتح EgyBook في نافذتين/جهازين، وتفاعل أو أضف تعليقًا في الأولى، وتأكد من تحديث الثانية والملف الشخصي وواجهة المنشور.
5. هذا التعديل لم يُختبر ضد مشروع Supabase الحي؛ تم التحقق من صياغة JavaScript فقط باستخدام node --check.

ملاحظة:
- نجاح التحديث الفوري يعتمد على تفعيل Realtime وصحة صلاحيات RLS والجداول الموجودة.
- هذا التعديل لا يحول خصائص أخرى غير متصلة بالسحابة (مثل بعض المحفوظات/الألبومات) إلى بيانات سحابية.
