# EgyBook V222 — Persistent Reels Session (Arabic)

## الهدف
الحفاظ على جلسة مشغل Reels نفسها عند التنقل بين صفحات الموقع والعودة، بدل إغلاق المشغل وإعادة إنشائه.

## السلوك
- عند مغادرة Reels من خلال تنقل داخلي، يتم إيقاف الفيديو مؤقتًا وإخفاء نافذة المشغل فقط.
- لا يتم حذف مصدر الفيديو أو استدعاء load() أو تفريغ عنصر الفيديو.
- تظل قائمة الفيديوهات والـpost الحالي ووقت التشغيل وحالة الصوت محفوظة في الذاكرة داخل نفس جلسة الصفحة.
- عند العودة إلى Reels، يتم إظهار عنصر المشغل نفسه واستئناف التشغيل إذا كان يعمل قبل المغادرة.
- يتم تحرير قفل تمرير الصفحة أثناء عرض الصفحات الأخرى ثم إعادته عند استرجاع المشغل.

## الملفات المعدلة
1. `script.js` — إضافة suspend/resume لجلسة المشغل، وتغيير مغادرة Reels من الإغلاق والتفريغ إلى الإيقاف والإخفاء المؤقت.
2. `egybook-reels-experience.js` — استعادة الجلسة المحفوظة قبل طلب أي فيديو جديد.
3. `index.html` — تحديث أرقام نسخ الملفات لمنع استخدام نسخة مخزنة قديمة.

## ما لم يتم تغييره
لم يتم تعديل ملفات المشغل CSS/JS أو swipe-navigation أو infinite-scroll أو أحداث اللمس أو قواعد CSS الخاصة بالتمرير. لم يتم تعديل مصدر الفيديو أو إعدادات preload أو منطق التنقل بين الريلز.

## الحدود
الحفظ مضمون أثناء التنقل الداخلي داخل نفس تحميل الصفحة (SPA). إذا أغلق المتصفح الصفحة بالكامل أو أعاد تحميلها أو قتل نظام الهاتف تبويب المتصفح، فلا يمكن الاحتفاظ بنفس عنصر الفيديو الحي؛ يلزم حينها استعادة موضع التشغيل من بيانات محفوظة وإعادة تهيئة المصدر. هذا الإصدار لا يدّعي ضمان الاستعادة بعد إغلاق الصفحة بالكامل.

## الاختبارات المنفذة
- فحص صياغة JavaScript باستخدام `node --check` للملفين المعدلين.
- فحص ساكن للتأكد من أن ملفات المشغل والسحب والتمرير لم تتغير بين V221 وV222.
- لم يتم إجراء اختبار حي داخل Chrome/WebView أو على حساب الموقع المنشور.

## النشر
ارفع محتويات مجلد `egybook_work` إلى الاستضافة واستبدل الملفات. لا يوجد SQL جديد ولا تعديل مطلوب في Neon أو Supabase أو Cloudflare Worker.
