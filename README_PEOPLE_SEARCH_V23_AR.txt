تحديث البحث عن الحسابات - EgyBook v23

الملفات المعدلة:
- index.html: واجهة البحث واقتراحات الحسابات وصفحة نتائج البحث.
- script.js: البحث في حسابات Supabase بالاسم واسم المستخدم، اقتراحات مباشرة، وفتح الملف الشخصي.
- styles.css: تصميم متجاوب بهوية EgyBook الداكنة ولمسات الأزرق والسماوي.

ملاحظات:
- البحث يعتمد على بيانات جدول public.profiles والأعمدة username وfull_name أو name.
- الاقتراحات تظهر أثناء الكتابة، وزر البحث/زر Enter يعرض صفحة نتائج كاملة.
- الضغط على حساب يفتح صفحة ملفه الشخصي باستخدام مسار اسم المستخدم الحالي.
- لم يتم تعديل ملفات SQL أو بيانات Supabase في هذا التحديث.
- يلزم اختبار البحث على الموقع بعد رفع الملفات، لأن الاتصال الفعلي بقاعدة البيانات لا يمكن تأكيده من ملف ZIP وحده.
