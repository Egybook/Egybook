# إصلاح تعليقات الريلز – V2

## ما الذي تغير؟
- إضافة `reels-comments.js` كوحدة مستقلة لواجهة تعليقات الريلز واتصالها بالـWorker.
- إضافة `reels-comments.css` لتصميم نافذة التعليقات والردود.
- إضافة نقطة ربط في `script.js`: عند فتح التعليقات داخل سياق الريلز يُرسل حدثًا للوحدة الجديدة ويتوقف المسار القديم قبل استدعاء تعليقات Supabase.
- تعليقات المنشورات العادية تظل على مسار Supabase القديم دون تغيير.
- إضافة مسار Worker لإنشاء/استرجاع ربط ثابت بين `posts.id` في Supabase و`reels.id` في Neon.
- إضافة `NEON_SQL.sql` لإنشاء جدول الربط `reel_post_links`.

## خطوات التفعيل المطلوبة
1. افتح Neon SQL Editor في مشروع `egybook-reels` ونفّذ `NEON_SQL.sql` مرة واحدة. هذا ملف جديد خاص بجدول الربط فقط؛ لا تعِد تنفيذ ترحيل التعليقات السابق.
2. انشر مجلد `cloudflare/egybook-reels-api` إلى Worker الحالي حتى يصبح المسار `/reels/by-post/{postId}` متاحًا.
3. ارفع ملفات الموقع كاملة من هذه الحزمة إلى الاستضافة.
4. اختبر فتح تعليقات ريل، ثم أضف تعليقًا وردًا وتفاعلًا، ثم أعد فتح الريل للتأكد من استمرار الحفظ.

## قواعد البيانات
- Neon: بيانات تعليقات الريلز وردودها وتفاعلاتها وإشعاراتها، بالإضافة إلى جدول الربط الجديد.
- Supabase: المصادقة وبيانات المستخدمين والملفات الشخصية.
- لا يوجد تعديل SQL مطلوب في Supabase لهذا الإصلاح؛ لذلك لم يُرفق `SUPABASE_SQL.sql` فارغ.

## حدود الاختبار
تم فحص صياغة JavaScript باستخدام `node --check` للملفات المعدلة والجديدة. لم يتم نشر Worker أو تنفيذ SQL على قاعدة حية أو اختبار جلسة مستخدم حقيقية من هذه البيئة.
