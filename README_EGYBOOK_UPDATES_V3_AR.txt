تحديث EgyBook — حزمة التعديلات المطلوبة
=======================================

تم تحديث المشروع انطلاقًا من النسخة المرفوعة EgyBook_Requested_Fixes_v2.zip مع الحفاظ على باقي ملفات المشروع.

التغييرات في هذه الحزمة:
1) الإشعارات:
   - بطاقات أكثر اختصارًا وتنسيقًا.
   - إزالة أزرار «عرض التعليق/عرض المنشور» وجعل البطاقة نفسها تفتح الهدف.
   - التعليقات والردود تفتح المنشور مع محاولة الوصول إلى التعليق/الرد المحدد.
   - إشعارات التفاعلات تفتح المنشور وتحاول فتح نافذة التفاعلات.
   - اسم صاحب الإشعار وصورته يفتحان ملفه الشخصي.
   - إضافة أيقونات SVG لنوع الإشعار ولعنوان صفحة الإشعارات.
   - حفظ موضع صفحة الإشعارات واستعادته عند الرجوع من المسار المرتبط.
2) القائمة الجانبية:
   - حركة انزلاق أهدأ وعرض أضيق.
   - تحريك محتوى الصفحة إلى الجانب عند فتح القائمة.
   - إغلاق بالنقر خارج القائمة أو Escape أو زر الرجوع في الهاتف.
   - منع مستمعات السحب لتحديث الصفحة من العمل أثناء فتح القائمة.
3) شارات التوثيق:
   - استخدام حالة حساب المستخدم الفعلية عند عرض الشارة في اسم الملف الشخصي والمنشورات والتعليقات/الردود.
   - الشارة الزرقاء للحساب الموثق والرمادية للحساب غير الموثق.
4) طلب التوثيق:
   - تعديل إرسال الطلب حتى لا يرسل قيمة plan غير موجودة في واجهة الطلب.
   - أُضيف ملف SQL لمعالجة عمود plan في قواعد البيانات القديمة.

مهم — مطلوب تشغيل SQL:
- افتح Supabase SQL Editor وشغّل الملف:
  EgyBook_VERIFICATION_PLAN_COMPATIBILITY_FIX.sql
- الملف يجعل عمود plan اختياريًا فقط إذا كان موجودًا في جدول verification_requests؛ لأن نموذج طلب التوثيق الحالي لا يجمع خطة اشتراك.
- لا يحتاج هذا الملف إلى إعادة تشغيل ملفات الهجرة القديمة.

الفحوصات التي تمت:
- اجتاز script.js فحص الصياغة باستخدام node --check.
- تم التحقق من سلامة إنشاء ملف ZIP.
- لم يتم اختبار السلوك على موقع الإنتاج أو الاتصال بقاعدة Supabase الحية من هذه البيئة؛ لذلك اختبر التصفح والإشعارات والتوثيق بعد رفع الملفات وتشغيل SQL.
